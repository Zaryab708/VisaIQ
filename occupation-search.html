Occupation & ANZSCO — common questions

What is an ANZSCO code?
ANZSCO (Australian and New Zealand Standard Classification of Occupations) is a 6-digit code identifying each occupation. It determines which skilled list you are on, which visas you qualify for, and which authority assesses your skills.
How do I find my occupation's points cutoff?
Search your occupation name or ANZSCO code above. VisaIQ shows the current EOI points cutoff from the latest SkillSelect round — the minimum competitive score for your occupation in 2026.
My occupation shows "Frozen" — what does that mean?
"Frozen" means the occupation received no subclass 189 invitations in the latest round (common for ICT and accounting). State nomination (190) or regional (491) pathways are usually the realistic route for these occupations.
